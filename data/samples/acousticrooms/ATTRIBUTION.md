# AcousticRooms sample

These files are an unmodified excerpt of the AcousticRooms dataset
(<https://github.com/facebookresearch/AcousticRooms>), (c) Meta Platforms, Inc.,
licensed under CC BY 4.0 (<https://creativecommons.org/licenses/by/4.0/>).
Only the folder layout was changed: each room's mesh, RIRs and per-pair
metadata sit together. `sample_index.json` was added by this project.

Rooms: MeetingRoom_idx_14, Bathrooms_idx_21.

Cite: Liu et al., "Hearing Anywhere in Any Environment", CVPR 2025. See `DATA_LICENSE.md`.
