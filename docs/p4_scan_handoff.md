# P4 scan-simulator handoff

P4 turns an audited AcousticRooms room into **partial scans** and places the
64 × 64 grid **from what each scan observed**. It is the scanner pose P3's
labels were waiting for: `build_scan_sample` returns P3's `GridFrame`, the
observed masks, and P3's target on that same grid, as contract v0.1.0 arrays.
RIR selection, splits and caching are P6.

## Interface

```python
from echospace.scans import RoomGeometry, build_scan_sample

room = RoomGeometry.from_mesh(mesh)            # Z-up AcousticRooms OBJ, sliced at 1.1 m
sample = build_scan_sample(room, room_id, "viewpoint", seed=0)   # or missing_wall, doorway, l_wing
arrays = sample.contract_arrays()              # observed_*, valid_cells, target_*, empty RIR rows
sample.grid.manifest_grid()                    # the record's "grid" block
sample.coverage, sample.coverage_bin           # observed wall share, "high" / "mid" / "low"
```

- `coverage_bin_name="low"` (or `mid`, `high`) redraws until the scan lands in
  that bin; `ScanNotFeasible` if it cannot (small rooms are always seen almost
  whole). `ScanNotApplicable` when a type cannot exist (L-wing on a convex room).
- `shift_m=1.0` is the plan's ±1 m training shift; `0` (default) gives the
  deterministic frame for fixed test masks. `wall_dropout` is the plan's
  optional sparse noise, off by default.
- Samples are seeded per `(room_id, occlusion type, seed)` and do not depend
  on call order.
- `GeometryLabelError("room clips scanner grid ...")`: the room does not fit
  the 12.8 m canvas around the observed anchor. The sample is refused, never
  clipped.

## What is simulated (plan 1.3)

| Type | How | Fixed parameters |
| --- | --- | --- |
| viewpoint | 1–3 full-turn scanners anywhere in the free floor | 360 rays, max range 5–8 m, 0.3 m clearance |
| missing wall | a viewpoint scan, then one *observed* wall (≥ 1 m) and everything within 1 m of it hidden | band 1 m |
| doorway | one scanner 0.5 m inside a wall, looking into the room | 120° field of view |
| L-wing | non-convex rooms only (footprint < 90 % of its hull); a wing cut off at a reflex corner, 10–50 % of the area, hidden; scanners outside it | |

- **Rays stop at everything in the 1.1 m slice, furniture included**, like a
  real LiDAR. Furniture hits are recorded as observed wall cells, so the input
  can contain obstacles that P3's target does not (P3 fills furniture loops).
  This is deliberate, and it makes the task honestly harder.
- Observed wall = cells containing a hit. Observed free = cells whose centre
  the rays swept, minus wall cells. Everything else is unobserved.
- Coverage = observed outer-wall length ÷ total outer-wall length (a wall point
  counts as seen within 0.15 m of a hit). Bins: high [0.65, 1], mid
  [0.40, 0.65), low [0.15, 0.40); below 0.15 a scan is redrawn as unusable.

## No-leakage frame (plan 1.2)

`observed_frame` receives the `Scan` and the scanner height, nothing else:

- **anchor**: centroid of the observed free space, snapped 0.1 m inside it when
  the centroid falls outside (L-shaped views);
- **heading**: length-weighted dominant direction of observed surfaces, folded
  to 90°, so observed walls align with the grid axes. Never the mesh axes.

Tests check that rotating a room rotates the heading, translating it moves the
anchor, and geometry the scanner cannot see leaves the frame unchanged.

## For P6 (splits, loader, cache)

- Fixed test masks: call with `shift_m=0` and a fixed seed per
  `(room, type, bin)`; `reports/p4_scans_summary.json` (`aimed_bins`) shows
  which combinations each room can produce.
- Valid RIRs: both positions must fall in `observed_free` (contract rule 4);
  if too few receivers survive, draw another scan.
- Group splits by `room_group` in `reports/d0_duplicates.json`.

## For P3 (open question)

P3's `target_boundary` is interior cells within 0.14 m of the outer wall; the
plan says "cells the polygon boundary passes through". P4 does not depend on
the choice, but the metrics will. Please settle it before P6 caches samples.
